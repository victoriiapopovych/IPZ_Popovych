# Student Portal

Student Portal is a client-server application for student registration, authentication, profile management, and student search.

The project is being developed as part of the Software Engineering course and represents a complete software system with a client application, server-side logic, database integration, and supporting technical documentation.

## Features

- User registration
- User authentication
- Personal profile viewing and editing
- Student search
- Viewing other student profiles
- Client-server communication
- Server-side request processing
- Database interaction

## Architecture

The system follows a client-server architecture.

The client application is responsible for user interaction and sending requests to the server.

The server processes client requests, validates incoming data, interacts with the database, and returns appropriate responses.

The application will be implemented in Python.
